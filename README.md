## 🚀 Free 1-Click Hosting on GitHub Pages

This project is configured out-of-the-box for **100% free hosting on GitHub Pages** with automated GitHub Actions CI/CD.

### Steps to host on GitHub for free:

1. **Create a GitHub Repository**:
   - Go to [GitHub.com](https://github.com) and create a new public or private repository (e.g. `vidyatree-publication`).

2. **Push your code to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Vidyatree Publication catalogue"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   git push -u origin main
   ```

3. **Enable GitHub Pages**:
   - In your GitHub repository, go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, select **GitHub Actions**.
   - The included workflow `.github/workflows/deploy.yml` will automatically build and publish your site at:
     `https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/`

## 🛠️ Local Development

To run the project locally on your machine:

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build production static bundle for deployment
npm run build
```
